# Implementation Worklog

## Status

Mode: product

Hero Scene Lab embeds the locally developed Recraft website as its canvas output and passes canonical values plus bounded gallery media through a version-21, origin-checked preview protocol. The website remains the visual owner of the prompt-free hero and renders either mirrored Rows with their frozen per-card optics or an autonomously scrolling infinite multi-row panel through a fixed separable lens and one scene→field→post dispersion pipeline. Each Sphere row can now own a separate ordered image set; once any per-row set is populated, empty rows stay empty instead of borrowing cards from another row. Uploading the first asset into an empty Row N drop complementarily grows Rows through Row N, while Remove Row keeps that drop's assets inactive until the user explicitly chooses Add Row. The heading group also owns a Figma-matched CTA whose copy, typography, paired padding, colors, distance, and independent shadow are edited in Toolcraft. Its V4 badge now has independent visibility, color, uniform vector scale, text distance, and shadow controls. Sphere now has only centre-anchored side zones; the removed top/bottom treatment no longer owns shader, protocol, control, acceptance, or browser-test state, and the panel remains pannable from its controls or directly on the Toolcraft canvas. Pan motion drives independently fading live TV Grain and CRT treatments, with a `0.05..3s` CRT Fade out control. Sphere startup stays visually pending until its initial textures settle or a bounded three-second wait expires, then reveals the already-projected WebGL scene in one short fade; the flat DOM gallery appears only after a proven WebGL failure.

## Delivery lifecycle

The first product delivery uses the protected functional gate recorded below. Later edits use only directly relevant feature work checks. A localized performance complaint may authorize one targeted iteration; only exact request authority may create measured targeted performance. A complete performance audit requires an explicit user request and uses `npm run verify:perf`.
