## Найденные причины и исправления

1. **Линии поверх картинок были и в оригинальном CSS:** `tiles: 1`, `grid: 2`. Подтверждена подготовленная коррекция слоёв: Fine Grid 0 → Main Grid 1 → Trail 2 → Tiles 3 → Back wall 4.
2. **Поворот/отражение могли не доходить до комнаты.** Повторные одинаковые массивы mediaAssets перезапускали эффект и отменяли декодирование. Селектор теперь сохраняет массив при семантически одинаковых изображениях и реагирует на реальные изменения источника, порядка, размеров, поворота и отражений.
3. **Комната блокировала перемещение Infinity-холста.** Обработчик нативной поверхности останавливал любое нажатие. Теперь он защищает интерактивные элементы; нажатие на фон проходит к стандартному перемещению холста.
4. **Тесты холста оставались привязаны к iframe.** Они переведены на настоящий нативный DOM. Исправлены недоступная переменная в browser observation, селектор textbox и несовпадение target у проверки сохранения. Проверки результата не удалены.

## Сохранённые отличия и публикация

- Website Apply отсутствует: приложение не записывает настройки в исходный сайт Recraft. Экспорт/импорт JSON настроек сохранён.
- Отдельная мобильная композиция оригинала ранее удалена; на узком холсте остаётся тот же рендер комнаты.
- Рендер нативный, без iframe; размеры и прокрутка привязаны к холсту редактора.
- Единственный источник картинок — прикреплённые файлы. Пустой загрузчик означает пустую комнату. Ранее сохранённую пустую коллекцию можно восстановить через Reset Tile Images без сброса остальных настроек.
