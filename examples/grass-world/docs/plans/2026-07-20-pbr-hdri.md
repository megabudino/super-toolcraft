# PBR Grass and HDRI Environment

Verification tier: Tier 4
Reason: This batch adds a new physical material branch, retained HDRI resources, custom file input and persistence, renderer/export invalidation, and broad acceptance coverage.
Run: `npm run ai:check`; targeted Vitest and Playwright checks while developing; `npm run verify:delivery` once at delivery; then `npm run dev` and verify the saved app URL.
Skip: No separate full-performance refresh because the request prioritizes image quality rather than performance optimization; the protected delivery runner decides the exact impact-derived performance set.

## Product behavior

- Keep Static and Dynamic as the primary preview modes. Add `appearance.pbrEnabled` as a Static-only switch; entering Dynamic disables PBR so its reduced blade sample remains a lightweight stylized preview.
- Preserve the current blade gradient as the grass albedo source. In PBR mode shade it with a double-sided physical grass material, normal-aware lighting, high roughness, subtle sheen and environment reflections.
- Add an `HDRI Environment` section visible only while Static PBR is active. It contains a built-in image picker for Meadow, Alps and Sunrise, a single custom Radiance `.hdr` file drop that overrides the preset while attached, intensity, world rotation, visible-background toggle and background blur.
- Bundle 1K CC0 HDR maps and compact previews from Poly Haven so presets work offline. Persist custom media with the rest of the project state.
- Use the same prepared environment in live preview, PNG/JPG export and video export. PNG keeps the Toolcraft Background Include contract; video always retains a background.
- Keep the existing top playback timeline and no layers. No new panel action is required.

## Implementation map

- Update `src/app/grass/grass-defaults.ts`, `grass-controls.ts`, `grass-values.ts`, `app-schema.ts`, `app-acceptance-data.ts` and `app-renderer-pipeline.ts` for the new state, controls, visibility, persistence and canonical pass inputs.
- Add focused HDRI preset metadata/assets under `src/app/grass/assets/hdri/`, decode Radiance RGBE inside a product-owned helper without importing prohibited model-loader infrastructure, and update `grass-scene.ts` to retain PMREM environment generation plus the physical material shader branch.
- Update `grass-output.tsx` to consume media assets, synchronize PBR with Static mode, await environment preparation and expose observable render evidence.
- Update `grass-export.ts` so all export renderers await the selected/custom environment before drawing frames.
- Add focused unit and browser tests for static-only PBR, every preset/settings path, custom HDRI upload/clear/persistence and rendered/exported pixels. Align `app-performance.ts`, `app-performance-impact.json` and browser adapters with new reachable targets and resource invalidation.
- Record the CC0 sources, decisions, checks and delivery result in `docs/toolcraft/agent-worklog.md`.

## Source selection

- Poly Haven Meadow 2: neutral bright meadow daylight for the default material setup.
- Poly Haven Alps Field: stronger crisp sunlight and higher contrast.
- Poly Haven Bloem Field Sunrise: warm low-angle lighting for rim and translucency evaluation.
- All three are distributed under Poly Haven's CC0 license.
